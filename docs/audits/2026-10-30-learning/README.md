# Independent iteration records

The observer task is to read each world’s outcome and distinguish captured
facts from candidate lessons. Both worlds remain together on the observation
screen; Research → Runs uses the existing paged reading surface.

## Found

The paired history writer required both worlds to be extinct simultaneously.
A fall could therefore lack a readable volume while the other world survived
or after asynchronous reseeding. Historical postmortems retain only 20 entries
in state; disk postmortems must supply earlier evidence. Model preventability
flags and inherited tags were presented with more causal certainty than the
record supports.

## Changed

Each fall has an immutable per-world report and an indexed record under the
configured data directory’s `history-books/`. Disk evidence and the in-memory
tail are merged by world and iteration. Explicit genesis archives the ledger
with the old run. Unknown historical dates and engine provenance are labelled,
not inferred from the current population. Lineage transitions are retained;
only changes inside known iteration bounds establish mixed-version counts.

Short Runs messages previously consumed the full reader height: the phone
empty state left about 514px between its last useful text and a disabled
pager. Single-page Runs now fit their content and omit that unused pager;
long reports retain the full reading budget. See `viewer/` for final geometry
and explicit synthetic UI fixtures at 390×844, 1024×768 and 1440×900.

The Runs reader puts observations before interpretations, preserves all
recorded values, and uses the existing pager. Archive errors and missing
coverage appear before the facts. Corrupt evidence and observer write errors
cannot stop the simulation; volumes, index and new postmortems use atomic
replacement. Invalid record identities cannot write outside the archive.

No engine, mind or needs-policy change was made. Engine 2026.10.30.1 and its
previous century arc remain the model evidence; no additional arc was run
for this observer-only change. EDEN receives no inherited assistance.

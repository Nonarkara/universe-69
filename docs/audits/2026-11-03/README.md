## Fuzzy logic with testable bounds

Each person has the same rules for **food, rest, company and intimacy**. A
stable seed/iteration/person/need identity gives the midpoint m in [.44,.56].
This is an illustrative, nonheritable preference, independent of existing
vigilance/executive-control genes; it does not invent an appetite-gene claim.

For bodily deficit x clamped to[0,1], overlapping memberships are:

| Input | Low | Moderate | High |
|---|---|---|---|
| x≤m | 1−x/m | x/m | 0 |
| x>m | 0 | (1−x)/(1−m) | (x−m)/(1−m) |

All memberships are nonnegative and sum to one. Weighted singleton outputs
0,.5,1 give response x/(2m) or .5+(x−m)/(2(1−m)). The result is continuous,
monotone, bounded0..1, exactly0/1 at its endpoints and at most.06 from neutral
identity. At m=.5 the rule is exactly identity. Membership means urgency,
**not probability**. [Mathematical references and model boundaries](../../../RESEARCH.md).

The same personal hunger response drives eating and own-body gathering urgency;
perceived camp scarcity is added afterward, so it cannot make a fed belly
hungry. Raw bodily emergencies, ongoing sleep, children, local perception,
kinship and independent mutual contact remain guarded. Intimacy meter refill
and actual-contact reset are unchanged. Company's existing option threshold
now acts on personal response. Final activity selection is discrete, including

## Adult anatomy boundary

Explicit external detail requires a known finite age>=18, uncovered hips and
an appropriate close view/non-intimate action. Unknown ages and all minors
fail closed. Garments covering the hips suppress genital detail; cloth is not
removed to expose it. Diagnostic nude studies contain only explicitly aged
adults. Child diagnostic figures have neutral anatomy without explicit detail.
These are nonsexual illustration tests, not clinical calibration or sex-act
renderings. The age boundary is unchanged from the existing house style.

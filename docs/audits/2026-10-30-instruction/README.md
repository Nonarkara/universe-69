## Changed

People remember only expertise actually demonstrated within local sight and
seek the last observed location. Remote movement does not update memory.
A contacted teacher independently chooses whether to explain the first missing
foundation or the desired technique. A requested lesson can therefore teach
tools before fishing, without prior tool awareness leaking through observation.

Instruction supplies awareness, not mastery; subsequent real fishing depletes
real stock and supplies practice. Verbal attention is bounded, shared by requested
and incidental lessons; passive work observation is distinct. Needs, night,
absence, deadlines and failed searches can stop a pursuit. Incidental conversations
and actual-work observations retain their existing exposure rules. Migration creates
no historical mentors and preserves existing procedures. Successful requested
instruction emits a cultural record entry; recording is observational.

The existing card/caption/diary shows intent. Tablet duplicate activity text
was removed from the compact heading; the full activity remains near the person.
No additional panels or controls. Mirrored viewer files remain identical.

intelligence. The prerequisite graph and all utilities/capacities/ranges/ages are
